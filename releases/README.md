# 固件版本发布归档

每个正式版本的完整交付物：可烧写固件 + 动画包 + 变更记录 + 烧写教程。

```
releases/
├── README.md                        ← 本文件：全部版本索引
└── v<主>.<次>.<修订>/                ← 一个正式版一个目录
    ├── CHANGELOG.md                 版本号 / 日期 / 功能变更 / ⚠硬件变更备注
    ├── 烧写说明.md                   用户视角的烧写教程（CH343 / 921600）
    ├── dshpet-vX.Y.Z-merged.bin     合并固件，地址 0 一键烧写
    ├── dshpet-vX.Y.Z-littlefs.bin   动画包，烧到 0x410000
    └── MD5SUMS.txt                  校验和，烧写前核对
```

## 发布流程

```
python tools/release.py v1.2.3
```

按提示录入本次功能变更与硬件变更，脚本自动构建、合并、生成文档。

## 版本规则（语义化）

- **主版本**：大功能架构调整，或硬件方案变更（换屏 / 换主控 / 加外设）
- **次版本**：新增功能
- **修订号**：bug 修复
