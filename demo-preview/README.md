# 肥鱼养成机 · 网页交互原型 Demo

把《养成互动宠物机系统开发计划》（固件计划）一比一做成浏览器可操作原型，
用于在写固件之前验收交互设计、视觉布局与数值手感。

## 怎么打开

**方式一（最省事）**：双击 `demo-preview/index.html`，用 Chrome / Edge 打开（`file://` 下能直接读本地 webm）。

**方式二（本地服务器，推荐给所有浏览器/IDE 内置预览）**：

```powershell
# 在项目根目录执行（不要在 demo-preview 里执行）
cd E:\AI\Porject\ESP\ESP32\dshPetDafeiyu
.\tools\start-demo.ps1
# 自动打开 http://localhost:8123/demo-preview/
```

> ⚠ **常见错误**：`cd demo-preview` 后再 `python -m http.server`——
> 这样站点根变成 demo-preview，页面里的 `../assets/...` 会越出站点根变成 404，
> 屏幕会进入「动画素材未加载」占位页。服务必须从**项目根**启动。

> 样式通过 CDN 引入 Tailwind，首次打开需联网；断网时 Tailwind 类失效，但自定义样式（全部核心视觉）仍然生效。

## 素材依赖与自动兜底

动画引用**西米 106 段真素材**（`../assets/source-webm/<分类>/<段名>.webm`）。webm 被全局 gitignore，clone 到新机器后需先在本地准备好素材。

页面启动时会**按顺序探测 5 个候选素材根**，第一个能加载的胜出（调试面板「素材根」一行可看到实际命中项）：

```
../assets/source-webm/       ← 标准（项目根/demo-preview/index.html）
/assets/source-webm/         ← http 服务根正好在项目根
assets/source-webm/          ← 页面位于站点根一级目录
../../assets/source-webm/    ← demo 放进更深一层
./assets/source-webm/        ← 把 assets 拷进 demo-preview
```

兜底行为分三层，避免「一次失败就整屏黑」：

| 情况 | 表现 |
|:---|:---|
| 单段加载失败 | 只在控制台告警，自动跳过该段、换同池其它段继续播 |
| 某池全坏 | 回落其它池（如待机皮肤逐个退让），不黑屏 |
| 所有候选根都失败 | 显示占位鱼 + 「动画素材未加载」+ 已尝试路径 + 修复指引，**按键与数值逻辑仍可正常体验** |

素材路径映射集中在 `js/mapping.js`，每个池的 `packs` 数组就是路径清单。

## 屏幕与按键

| 项目 | 说明 |
|:---|:---|
| 屏幕 | 320×240 逻辑像素 × 2 = 640×480 显示，圆角拟物外壳 |
| 状态栏 | 顶部 28 逻辑像素（56 显示像素）overlay：左上 🍚 白饭星级（金色）、右上 🐟 心情星级（青色），5 星 × 半星制 10 档 |
| 飘字 | 互动提示 1.5 秒后自动消失 |
| 按键 | 2×2 布局：投喂白饭（左上）/ 摸鱼玩耍（右上）/ 打工跑代码（左下）/ 撸鱼贴贴（右下），短按互动、长按 2 秒二级功能 |

## 玩法与数值（与固件计划完全一致）

| 操作 | 数值变化 |
|:---|:---|
| 投喂白饭（短按） | 白饭 +5（半星）· 心情 +2.5 · 干饭碗 +1 |
| 摸鱼玩耍（短按） | 心情 +10（半星×2）· 白饭 −5 |
| 打工跑代码（短按） | 白饭 −10 · Token +10 · 心情 −5 |
| 撸鱼贴贴（短按） | 心情 +10 · 无消耗 |
| 自然衰减 | 每 2 小时白饭 −10、心情 −10（demo 每 30 秒，0 封底无惩罚） |

两个数值 0~100，每 10 分 = 半星档，100 = 5 星满。

## 长按二级功能

| 按键 | 长按 2 秒 |
|:---|:---|
| 投喂白饭 | 📋 状态详情页（星级 / 累计干饭碗数 / 累计 Token） |
| 摸鱼玩耍 | 切换待机皮肤：发呆 → 吐泡泡 → 晃尾巴（循环） |
| 打工跑代码 | 📈 累计数据页（历史总 Token / 总干饭碗数 / 称号） |
| 撸鱼贴贴 | ⚙ 系统设置（屏幕亮度 / 自动休眠 / 提示音效置灰） |

页面打开时动画暂停、衰减冻结（互斥），任意短按返回。

## 彩蛋与联动

| 触发 | 效果 |
|:---|:---|
| 2 秒内连按投喂 3 次 | 「吃太饱啦！摸鱼消消食」+ 1.5× 加速转圈，10 秒内白饭不再上涨 |
| 2 秒内连按打工 5 次 | 「鱼鱼好累，要摸鱼休息」+ 0.5× 减速螃蟹走路抗议 10 秒 |
| 累计 Token 100 / 500 / 1000 | 庆祝动画（排队在当前互动之后播，不被覆盖）+ 解锁称号：实习码鱼 / 摸鱼组长 / 首席干饭官 |
| 双 5 星满状态 | 待机随机触发庆祝小动作 |
| 2 星及以下 | 待机动画 0.5× 减速（无精打采） |
| 双 0 值 | 打瞌睡动画 0.25×（互动后立即恢复） |
| 5 分钟无操作 | 低亮度休眠，任意键唤醒（唤醒那一下不触发功能） |

## 调试面板（右侧）

- **模拟倍速**：1× / 10× / 60×，同时作用于衰减与休眠倒计时（60× 下 5 分钟休眠 ≈ 5 秒，30 秒衰减 ≈ 0.5 秒）
- **调试面板**：当前动画池、当前段文件、播放速率、星级档位、联动状态、Token/称号、下次衰减倒计时、休眠状态
- **重置存档**：清空 localStorage 恢复初始值并唤醒

## 存档

数值存 localStorage（key `feiyu-demo-save-v1`），模拟固件 NVS 掉电不丢。
**跨刷新不补衰减**——与固件「无 RTC、跨掉电时间差不补偿」的取舍一致。

## 与固件计划的对应关系

| 本 demo | 固件模块 | 说明 |
|:---|:---|:---|
| `js/stats.js` | `stats.cpp`（新建） | 数值增减、10 档星级、衰减结算、里程碑 |
| `js/animator.js` | `animator.cpp`（重构） | 分池抽签、播完回落待机、变速、优先级排队 |
| `js/overlay.js` | `overlay.cpp`（新建） | 状态栏星级、1.5 秒飘字 |
| `js/menus.js` | `menus.cpp`（新建） | 三个长按页面与互斥 |
| `js/sleep.js` | sleep 行为 | 无操作休眠与任意键唤醒 |
| `js/mapping.js` | `config.h` 映射数组 | 池 → 素材路径，换角色只改这一处 |
| `js/main.js` | `main.cpp` | 事件循环：按键 → 数值/动画/页面 → 联动 |

固件实现时数值口径、彩蛋窗口（2s）、长按判定（2s）、池回落行为都照此照抄即可。

## 已知限制

- 素材 640×360 与屏幕 4:3 比例不同，`object-fit: cover` 居中裁切（与流水线裁切逻辑视觉一致）
- 屏幕亮度用 CSS `filter: brightness()` 模拟背光，固件侧需用 LEDC PWM（计划中已标注风险）
- 提示音效无硬件，设置项置灰占位
- 素材完全不可用时进入占位模式（占位鱼 + 修复指引），按键与数值逻辑仍可正常体验
